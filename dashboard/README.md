# Power BI Dashboard

The Power BI report contains four pages that translate the SQL analysis into an interactive business-intelligence experience.

## Report pages

1. **Executive Overview** — KPI cards, monthly sales trend, sales by category and country, quantity by country, customer gender mix, average order value by country, and monthly customer/quantity trend.
2. **Sales Analysis** — year-over-year KPIs, running total sales, average price vs moving average, current vs previous-year sales, and a monthly performance table.
3. **Product Analysis** — top/bottom product rankings, product cost ranges, product performance groups, category contribution, and detailed product performance.
4. **Customer Analysis** — customer-segment KPIs, age groups, customer segments, top customers, and detailed customer-level metrics.

## Files

- `Retail_Business_Intelligence.pbix` — downloadable Power BI Desktop project.
- `screenshots/` — static previews of the four report pages for GitHub/portfolio viewing.
