# Project Report

This folder contains the written project report documenting the end-to-end workflow from SQL exploration to Power BI reporting.

The report covers:

- Project overview and analytical model
- Exploratory SQL analysis
- Advanced SQL analysis
- SQL refinements and recommended improvements
- Power BI dashboard pages
- Key findings and interpretations
- Business recommendations
- Conclusion and future scope

The PDF is intended to complement the repository code and dashboard by explaining the business questions, analytical reasoning, and relationship between SQL outputs and Power BI visuals.
